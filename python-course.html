Learn Python

Python reads almost like plain English, which makes it one of the friendliest languages to start programming in — and one of the most used, from scripting to data science to backend servers. Work through the lessons below, then try the code yourself in the Playground's Python mode.

1. Variables & Types 2. Strings 3. Lists & Tuples 4. Dictionaries & Sets 5. Conditionals 6. Loops 7. Functions 8. Classes & OOP 9. Inheritance 10. Error Handling 11. File I/O 12. Modules & Packages 13. List Comprehensions 14. Decorators 15. The Standard Library
Lesson 1

Variables & Data Types

Python is dynamically typed — you never declare a type, the interpreter figures it out from the value you assign. The core built-in types are int, float, str, and bool.

name = "Frontend Forge" # str lessons = 15 # int rating = 4.9 # float is_free = True # bool print(type(lessons)) # <class 'int'> print(f"{name} has {lessons} lessons")

Use snake_case for variable names by convention, and remember that reassigning lessons = "fifteen" is perfectly legal — the variable just points at a new object of a different type.

Lesson 2

Strings

Strings support slicing, concatenation, and a large set of built-in methods. f-strings (prefixed with f) are the modern way to embed expressions directly inside string literals.

course = "python" print(course.upper()) # "PYTHON" print(course[0:3]) # "pyt" — slice print(course.replace("py", "PY")) score = 87 message = f"You scored {score}% — {'Passed' if score >= 50 else 'Try again'}" print(message)

String slicing [start:stop] never includes the stop index, and negative indices count from the end — course[-1] is the last character. Strings are also immutable: every method above returns a new string rather than modifying the original.

Lesson 3

Lists & Tuples

A list is an ordered, mutable collection — add, remove, and reorder freely. A tuple looks similar but is immutable once created, which makes it useful for fixed data like coordinates.

courses = ["HTML", "CSS", "JavaScript"] courses.append("Python") courses[0] = "HTML5" print(courses[-1]) # "Python" point = (35.6, 139.7) # tuple — can't be changed lat, lng = point # unpacking
Lesson 4

Dictionaries & Sets

A dict stores key-value pairs for fast lookup by name instead of position. A set stores only unique values with no order — perfect for membership checks and removing duplicates.

course = { "name": "Python", "lessons": 15, "topics": ["syntax", "OOP", "files"] } print(course["lessons"]) # 15 course["level"] = "Beginner" # add a new key completed = {"html", "css", "python"} completed.add("javascript") print("css" in completed) # True

Use course.get("level", "Unknown") instead of course["level"] when a key might be missing — get returns a default instead of raising a KeyError.

Lesson 5

Conditionals

Python uses indentation, not curly braces, to mark which lines belong inside an if/elif/else block — get the whitespace wrong and the code won't run.

score = 72 if score >= 90: grade = "A" elif score >= 70: grade = "B" else: grade = "C" print(grade) # "B" print("Pass" if score >= 50 else "Fail") # ternary

Python has no switch statement in most released versions before 3.10 — chained elif is the standard pattern, and match/case (3.10+) is the closer equivalent for matching against several fixed values.

Lesson 6

Loops

for loops iterate directly over a collection's items — no manual index counter needed — while while loops repeat as long as a condition stays true. range() generates a sequence of numbers when you do need a counter.

for course in ["HTML", "CSS", "Python"]: print(f"Learning {course}") for i in range(3): print(i) # 0, 1, 2 attempts = 0 while attempts < 3: attempts += 1

break exits a loop immediately, and continue skips straight to the next iteration — both work identically inside for and while.

Lesson 7

Functions

def defines a reusable block of code. Parameters can have default values, and *args/**kwargs let a function accept any number of extra positional or named arguments.

def greet(name, greeting="Hello"): return f"{greeting}, {name}!" print(greet("Learner")) # "Hello, Learner!" print(greet("Learner", greeting="Hi")) # "Hi, Learner!" def total(*scores): return sum(scores) print(total(80, 92, 76)) # 248

Functions are first-class objects — you can pass one as an argument to another, store it in a variable, or return it from a function, just like any other value.

Lesson 8

Classes & OOP

A class bundles data and behavior together. __init__ is the constructor, called automatically when you create a new instance, and self refers to that specific instance inside every method.

class Course: def __init__(self, name, lessons): self.name = name self.lessons = lessons self.completed = 0 def progress(self): return round(self.completed / self.lessons * 100) py = Course("Python", 15) py.completed = 6 print(py.progress()) # 40

Every method needs self as its first parameter so Python knows which instance's data to work with — it's passed automatically when you call py.progress(), you never pass it yourself.

Lesson 9

Inheritance

A subclass inherits every method and attribute from its parent by putting the parent's name in parentheses, and can override or extend behavior. super() calls the parent's version of a method from inside the child's.

class CertifiedCourse(Course): def __init__(self, name, lessons): super().__init__(name, lessons) self.certified = False def certify(self): if self.progress() >= 50: self.certified = True return self.certified py = CertifiedCourse("Python", 15) py.completed = 9 py.certify() # True
Lesson 10

Error Handling

try/except catches an error instead of letting it crash the whole program. Catch specific exception types where possible rather than a bare except, so you don't accidentally swallow bugs you didn't expect.

def safe_divide(a, b): try: return a / b except ZeroDivisionError: print("Can't divide by zero") return None except TypeError: print("Both values must be numbers") return None finally: print("Division attempted") safe_divide(10, 0)

The finally block always runs, whether an exception was raised or not — useful for cleanup like closing a file or a network connection.

Lesson 11

File I/O

The with statement opens a file and guarantees it gets closed afterward, even if an error occurs partway through — no need for a manual close() call.

with open("progress.txt", "w") as f: f.write("Python: 60%\n") f.write("HTML: 100%\n") with open("progress.txt", "r") as f: for line in f: print(line.strip())

Mode strings control behavior: "w" overwrites the file, "a" appends to the end, and "r" (the default) opens for reading only — opening a missing file in "r" mode raises a FileNotFoundError.

Lesson 12

Modules & Packages

Any .py file is automatically a module other files can import. A folder containing an __init__.py is a package — a namespace for grouping related modules together.

# utils.py def slugify(text): return text.lower().replace(" ", "-") # main.py import utils from utils import slugify as make_slug print(utils.slugify("Learn Python")) # "learn-python" print(make_slug("Frontend Forge"))

import module requires prefixing every call with the module name; from module import name pulls a specific function or class directly into your file's namespace, optionally renamed with as.

Lesson 13

List Comprehensions

A comprehension builds a new list from an existing iterable in a single readable line, optionally filtering with an if clause — the same result as a for loop with .append(), but more idiomatic Python.

scores = [55, 92, 40, 78, 61] passed = [s for s in scores if s >= 50] # [55, 92, 78, 61] doubled = [s * 2 for s in scores] grades = {s: ("Pass" if s >= 50 else "Fail") for s in scores}

The same syntax works for building sets ({...}) and dictionaries ({k: v for ...}) — collectively these are called comprehensions, and they run faster than an equivalent manual loop.

Lesson 14

Decorators

A decorator is a function that wraps another function to add behavior — logging, timing, access control — without changing the original function's code. The @ syntax is shorthand for passing a function into another and reassigning the name.

import time def timed(func): def wrapper(*args, **kwargs): start = time.time() result = func(*args, **kwargs) print(f"{func.__name__} took {time.time() - start:.4f}s") return result return wrapper @timed def load_lessons(course): return [f"Lesson {i}" for i in range(course)] load_lessons(15)

@timed above def load_lessons is exactly equivalent to writing load_lessons = timed(load_lessons) — the decorator receives the original function and returns a replacement.

Lesson 15

The Standard Library

Python ships with a huge "batteries included" standard library, so many common tasks need no external installation at all — json for parsing data, datetime for dates, random for randomness, and collections for specialized data structures.

import json from datetime import date from collections import Counter data = json.dumps({"course": "Python", "lessons": 15}) today = date.today() topics = ["oop", "loops", "oop", "files", "loops", "oop"] print(Counter(topics).most_common(1)) # [('oop', 3)]

Counter tallies occurrences in one call instead of a manual loop with a dictionary, and json.dumps/json.loads mirror JavaScript's JSON.stringify/JSON.parse for exchanging data between the two languages.
