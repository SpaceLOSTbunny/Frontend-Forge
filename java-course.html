Learn Java

Java is a strictly-typed, object-oriented language that powers everything from Android apps to enterprise backends. Its explicitness makes intent clear at a glance. Work through the lessons below, then try the code yourself in the Playground's Java mode.

1. Setup & Syntax 2. Variables & Types 3. Conditionals 4. Loops 5. Arrays 6. Methods 7. Classes & Objects 8. Constructors & this 9. Inheritance 10. Interfaces & Abstract Classes 11. Collections 12. Exceptions 13. Generics 14. Static vs Instance 15. String Formatting & Enums
Lesson 1

Setup & Program Structure

Every Java program lives inside a class, and execution always starts at a special method called main. The filename must match the public class name exactly — Main.java for class Main.

public class Main { public static void main(String[] args) { System.out.println("Hello, Frontend Forge!"); } }

Unlike JavaScript or Python, Java is compiled — javac Main.java produces bytecode that the Java Virtual Machine (JVM) then runs with java Main, which is what lets the same compiled file run unchanged on any OS with a JVM installed.

Lesson 2

Variables & Types

Java is statically typed: every variable's type is declared up front and checked at compile time, before the program ever runs. Primitives (int, double, boolean, char) hold raw values directly; everything else is an object reference.

int lessons = 15; double rating = 4.9; boolean isFree = true; char grade = 'A'; String name = "Java"; // object, not a primitive final int MAX_ATTEMPTS = 3; // final = constant, can't be reassigned

Mismatching types is a compile error, not a runtime surprise — writing int lessons = "fifteen"; won't even build. This upfront checking is exactly what catches whole categories of bugs before the code ever runs.

Lesson 3

Conditionals

if/else if/else works with curly braces marking each block, and Java also has a switch statement for matching one value against several fixed cases.

int score = 72; String grade; if (score >= 90) { grade = "A"; } else if (score >= 70) { grade = "B"; } else { grade = "C"; } switch (grade) { case "A" -> System.out.println("Excellent"); case "B" -> System.out.println("Good"); default -> System.out.println("Keep going"); }

The arrow form (case "A" -> ...) is the modern Java syntax and doesn't "fall through" to the next case automatically like the older colon-based switch did.

Lesson 4

Loops

Java offers a classic C-style for loop with an explicit counter, an enhanced for-each for iterating collections directly, and while/do-while for condition-driven repetition.

for (int i = 0; i < 3; i++) { System.out.println(i); } String[] courses = {"HTML", "CSS", "Java"}; for (String course : courses) { System.out.println(course); } int attempts = 0; while (attempts < 3) { attempts++; }

The for-each form (for (String course : courses)) reads "for each course in courses" and avoids off-by-one indexing bugs entirely — reach for it whenever you don't need the index itself.

Lesson 5

Arrays

An array holds a fixed number of elements of the same type, decided at creation time — unlike a list, its length can't change afterward. Multi-dimensional arrays nest one array inside another for grids.

int[] scores = {85, 92, 78}; scores[0] = 90; System.out.println(scores.length); // 3 int[][] grid = new int[3][3]; // 3x3 grid, all zeros grid[1][1] = 1;
Lesson 6

Methods

A method's signature declares its return type, name, and parameter types up front. Use void when a method performs an action but returns nothing.

public static int square(int n) { return n * n; } public static void printProgress(String course, int percent) { System.out.println(course + ": " + percent + "%"); } square(6); // 36 printProgress("Java", 40);

Java supports method overloading — multiple methods with the same name but different parameter lists — letting add(int, int) and add(double, double) coexist as distinct methods the compiler picks between.

Lesson 7

Classes & Objects

A class defines fields (data) and methods (behavior); an object is a specific instance created from it with new. Each object has its own independent copy of the class's fields.

public class Course { String name; int lessons; int completed; int progress() { return completed * 100 / lessons; } } Course java = new Course(); java.name = "Java"; java.lessons = 15; java.completed = 6; System.out.println(java.progress()); // 40
Lesson 8

Constructors & this

A constructor is a special method, matching the class name, that runs automatically when you use new. The this keyword refers to the current object, most often needed to disambiguate a field from a parameter of the same name.

public class Course { String name; int lessons; public Course(String name, int lessons) { this.name = name; // this.name = field, name = parameter this.lessons = lessons; } } Course java = new Course("Java", 15);

Without this.name = name, the line would just reassign the parameter to itself and the field would stay uninitialized — this is what tells Java "the object's field," not "the local variable."

Lesson 9

Inheritance

extends lets one class inherit fields and methods from a parent, and @Override marks a method that intentionally replaces the parent's version — the compiler warns you if the signature doesn't actually match anything to override.

public class CertifiedCourse extends Course { boolean certified; public CertifiedCourse(String name, int lessons) { super(name, lessons); // call the parent constructor } @Override public String toString() { return name + " (" + lessons + " lessons)"; } }
Lesson 10

Interfaces & Abstract Classes

An interface declares method signatures with no implementation — a contract any class can implement. An abstract class can mix fully-implemented methods with abstract ones that subclasses must fill in.

public interface Gradeable { String grade(); } public class Quiz implements Gradeable { int score; @Override public String grade() { return score >= 50 ? "Pass" : "Fail"; } }

A class can implement multiple interfaces but only extend one class — interfaces are Java's way of sharing a contract across unrelated classes without the limits of single inheritance.

Lesson 11

Collections: ArrayList & HashMap

Unlike a fixed-size array, ArrayList grows and shrinks as needed. HashMap stores key-value pairs for fast lookup by key — both live in java.util and need to be imported.

import java.util.ArrayList; import java.util.HashMap; ArrayList<String> courses = new ArrayList<>(); courses.add("Java"); courses.remove("Java"); HashMap<String, Integer> progress = new HashMap<>(); progress.put("Java", 40); System.out.println(progress.get("Java")); // 40

The <String> and <String, Integer> angle brackets are generics — they tell the compiler exactly what type the collection holds, so putting the wrong type in is a compile error, not a runtime surprise.

Lesson 12

Exceptions

try/catch/finally handles errors, same shape as most languages. Java distinguishes checked exceptions (must be declared or caught, like IOException) from unchecked ones (like ArithmeticException) that the compiler doesn't force you to handle.

public static int safeDivide(int a, int b) { try { return a / b; } catch (ArithmeticException e) { System.out.println("Can't divide by zero: " + e.getMessage()); return 0; } finally { System.out.println("Division attempted"); } }

Use throw new IllegalArgumentException("message") to raise your own exception when input is invalid — Java's standard library ships dozens of built-in exception types for common failure cases.

Lesson 13

Generics

Generics let you write a class or method once that works with any type, while the compiler still enforces type safety — Box<String> and Box<Integer> share the same code but each only accepts its own type.

public class Box<T> { private T content; public void set(T content) { this.content = content; } public T get() { return content; } } Box<String> nameBox = new Box<>(); nameBox.set("Java"); Box<Integer> scoreBox = new Box<>(); scoreBox.set(92);

T is just a placeholder name (short for "Type") chosen by convention — the compiler substitutes the real type in wherever the generic is used, catching type mismatches before the program even runs.

Lesson 14

Static vs Instance

A static field or method belongs to the class itself, shared across every instance — call it directly on the class name. An instance member belongs to each individual object and needs an object to be called on.

public class Course { static int totalCourses = 0; // shared by every Course String name; // unique per instance public Course(String name) { this.name = name; totalCourses++; } } new Course("HTML"); new Course("Java"); System.out.println(Course.totalCourses); // 2
Lesson 15

String Formatting & Enums

String.format builds formatted text with placeholders, similar to an f-string. An enum defines a fixed, named set of constant values — safer than plain strings because the compiler rejects anything outside the set.

enum Level { BEGINNER, INTERMEDIATE, ADVANCED } Level current = Level.BEGINNER; String summary = String.format( "Course: %s | Progress: %d%% | Level: %s", "Java", 40, current ); System.out.println(summary);

switch (current) over an enum only needs to list the enum's own values, and the compiler can warn you if a case is missing — a common source of copy-paste bugs with plain strings that enums close off entirely.
