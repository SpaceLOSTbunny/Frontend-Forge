Learn C++

C++ gives you direct control over memory and performance, which is exactly why it powers game engines, operating systems and high-frequency trading systems. It's a stricter language, but understanding it makes every other language's abstractions click. Work through the lessons below, then try the code yourself in the Playground's C++ mode.

1. Setup & Syntax 2. Variables & Types 3. Conditionals 4. Loops 5. Arrays & Vectors 6. Functions 7. Pointers 8. References 9. Classes & Objects 10. Constructors & Destructors 11. Inheritance & Polymorphism 12. Memory Management 13. STL Containers 14. Templates 15. Standard Library Algorithms
Lesson 1

Setup & Program Structure

Every C++ program starts execution in main(). #include pulls in a header so its functions become available, and std:: prefixes names that come from the standard library's std namespace.

#include <iostream> int main() { std::cout << "Hello, Frontend Forge!" << std::endl; return 0; }

C++ is compiled ahead of time into native machine code — a compiler like g++ turns this source into an executable before it ever runs, which is why C++ programs tend to run faster than interpreted languages but need a build step first.

Lesson 2

Variables & Types

C++ is statically typed like Java, with fine-grained control over exactly how much memory a value takes — int, double, char, bool, and std::string for text.

int lessons = 15; double rating = 4.9; bool isFree = true; char grade = 'A'; std::string name = "C++"; const int MAX_ATTEMPTS = 3; // const = can't be reassigned

auto lets the compiler infer a variable's type from its initializer — auto lessons = 15; is still strictly typed as int underneath, just without writing it out.

Lesson 3

Conditionals

if/else if/else and switch work much like Java's, with curly braces marking each block.

int score = 72; std::string grade; if (score >= 90) { grade = "A"; } else if (score >= 70) { grade = "B"; } else { grade = "C"; } std::cout << (score >= 50 ? "Pass" : "Fail");

C++'s switch falls through to the next case unless you add break; — a common source of bugs, and one reason many style guides prefer chained if/else if for anything beyond a few simple cases.

Lesson 4

Loops

for, while, and do-while all exist, plus a range-based for for iterating a container directly without manual indexing.

for (int i = 0; i < 3; i++) { std::cout << i << "\n"; } std::vector<std::string> courses = {"HTML", "CSS", "C++"}; for (const auto& course : courses) { std::cout << course << "\n"; }

const auto& in the range-based loop avoids copying each element — const means the loop body can't modify it, and & means it's a reference to the original, not a copy.

Lesson 5

Arrays & Vectors

A raw C-style array has a fixed size decided at compile time. std::vector (from the STL) is the modern, safer default — it resizes dynamically and manages its own memory.

int scores[3] = {85, 92, 78}; // fixed-size array scores[0] = 90; std::vector<int> scoreList = {85, 92, 78}; scoreList.push_back(95); // grows automatically std::cout << scoreList.size(); // 4
Lesson 6

Functions

Like Java, a function's return type and parameter types are declared explicitly. Parameters are passed by value (a copy) unless you use a reference or pointer to modify the caller's original variable.

int square(int n) { return n * n; } void printProgress(std::string course, int percent) { std::cout << course << ": " << percent << "%\n"; } square(6); // 36 printProgress("C++", 25);
Lesson 7

Pointers

A pointer stores a variable's memory address rather than its value directly. & gets the address of a variable, and * either declares a pointer or dereferences one to reach the value it points to.

int lessons = 15; int* ptr = &lessons; // ptr holds the address of lessons std::cout << ptr; // prints the memory address std::cout << *ptr; // prints 15 — dereferenced *ptr = 20; // changes lessons through the pointer std::cout << lessons; // 20
Lesson 8

References

A reference is an alias for an existing variable — declared with & at the type, not the variable name — and unlike a pointer it can't be null or reassigned to refer to something else. Passing by reference lets a function modify the caller's variable without pointer syntax.

void addLesson(int& total) { total = total + 1; // modifies the caller's variable directly } int lessons = 15; addLesson(lessons); std::cout << lessons; // 16

Rule of thumb: prefer references for function parameters when you just need to read or modify an existing value, and reach for pointers when you need the ability to represent "no value" (nullptr) or to reassign what's being pointed to.

Lesson 9

Classes & Objects

A C++ class groups data and methods, with public/private controlling access. Private members are only reachable from inside the class's own methods — the basis of encapsulation.

class Course { private: int completed = 0; public: std::string name; int lessons; int progress() { return completed * 100 / lessons; } }; Course cpp; cpp.name = "C++"; cpp.lessons = 15;

completed being private means outside code can't touch it directly — only Course's own methods can, which is what keeps an object's internal state from being changed in ways the class didn't intend.

Lesson 10

Constructors & Destructors

A constructor initializes an object when it's created; a destructor (prefixed ~) runs automatically when the object goes out of scope or is deleted — the natural place to release any resources it was holding.

class Course { public: std::string name; Course(std::string n) : name(n) { // constructor std::cout << name << " created\n"; } ~Course() { // destructor std::cout << name << " destroyed\n"; } }; { Course cpp("C++"); } // destructor runs automatically here, at end of scope

This automatic cleanup at end-of-scope is called RAII (Resource Acquisition Is Initialization) — it's the core idiom that makes C++ memory-safe without needing a garbage collector, as long as resources are wrapped in objects like this.

Lesson 11

Inheritance & Polymorphism

: public Base inherits from a parent class. Marking a method virtual enables polymorphism — calling it through a base-class pointer runs the derived class's version, not the base's.

class Course { public: virtual std::string describe() { return "A course"; } }; class CertifiedCourse : public Course { public: std::string describe() override { return "A certified course"; } }; Course* c = new CertifiedCourse(); std::cout << c->describe(); // "A certified course"

Without virtual, that same call would print "A course" — the base class's version — because the compiler would resolve the method by the pointer's declared type, not the object's actual type.

Lesson 12

Memory Management

new allocates memory on the heap that lasts until you explicitly free it with delete — forget to, and it's a memory leak. Modern C++ prefers smart pointers that free memory automatically when nothing references it anymore.

int* raw = new int(15); delete raw; // must free manually #include <memory> std::unique_ptr<int> smart = std::make_unique<int>(15); // freed automatically when smart goes out of scope — no delete needed

std::unique_ptr owns its memory exclusively and cleans up via the same RAII pattern as destructors; std::shared_ptr allows multiple owners and frees the memory once the last one goes out of scope.

Lesson 13

STL Containers

The Standard Template Library ships ready-made data structures beyond vector: std::map for key-value pairs (kept sorted by key), std::set for unique values, and std::pair for bundling two values together.

#include <map> #include <set> std::map<std::string, int> progress; progress["C++"] = 25; progress["Java"] = 40; std::set<std::string> completed = {"html", "css"}; completed.insert("cpp"); std::pair<std::string, int> top("C++", 25);

Every STL container shares a consistent interface — .size(), .begin(), .end() — which is exactly what lets generic algorithms like std::sort work on almost any of them without modification.

Lesson 14

Templates

A template lets you write one function or class that works with any type, with the compiler generating a specialized version for each type actually used — this is how std::vector<T> itself is implemented.

template <typename T> T maxOf(T a, T b) { return (a > b) ? a : b; } maxOf(3, 7); // works with int maxOf(3.5, 2.1); // works with double maxOf(std::string("a"), std::string("b")); // works with string
Lesson 15

Standard Library Algorithms

<algorithm> provides ready-made, well-tested operations — sorting, searching, transforming — that work across any STL container through iterators, so you rarely need to hand-write a sort or search loop yourself.

#include <algorithm> #include <vector> std::vector<int> scores = {72, 95, 40, 88}; std::sort(scores.begin(), scores.end()); bool anyFailing = std::any_of(scores.begin(), scores.end(), [](int s) { return s < 50; }); auto it = std::find(scores.begin(), scores.end(), 88);

The [](int s) { return s < 50; } is a lambda — a small anonymous function defined inline, exactly where it's needed, without giving it a separate name.
