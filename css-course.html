Learn CSS

CSS is what turns plain HTML into something people actually want to look at — color, spacing, layout and motion. Work through the lessons below, then head to the Practice Zone to test what you've learned.

1. Selectors 2. Box Model 3. Color & Units 4. Flexbox 5. Grid 6. Responsive Design 7. Pseudo-classes 8. Positioning 9. Animations 10. Specificity 11. Custom Properties 12. Gradients & Shadows 13. Transforms & 3D 14. calc(), clamp() & min/max 15. Grid Template Areas
Lesson 1

Selectors

CSS rules pair a selector with a set of declarations. An element selector targets a tag, a class selector (.name) targets any element with that class, and an ID selector (#name) targets exactly one element.

p { color: #444; } .card { padding: 20px; } #main-header { font-weight: 700; }

Classes are reusable and reach for them by default — reserve IDs for one-off, unique elements like a page's main header.

Lesson 2

The Box Model

Every element is a rectangular box made of four layers, from the inside out: content, padding, border, and margin. Understanding this stack is the key to controlling spacing.

.card { padding: 20px; /* space inside the border */ border: 1px solid #ddd; margin: 16px 0; /* space outside the border */ box-sizing: border-box; /* padding/border don't add to width */ }

box-sizing: border-box is a near-universal default in modern CSS — it makes an element's declared width include its padding and border, so sizing stays predictable.

Lesson 3

Color, Typography & Units

Colors can be named, hex, or rgb(). Sizing units matter too: px is fixed, % is relative to the parent, em is relative to the current font size, and rem is relative to the root font size — usually the safest choice.

body { font-family: 'Inter', sans-serif; font-size: 1rem; color: #222; } h1 { font-size: 2.5rem; font-weight: 700; color: rgb(255, 107, 53); }

Prefer rem for font sizes and spacing — it scales consistently if a user changes their browser's base font size for accessibility.

Lesson 4

Flexbox

Flexbox lays out items in a single row or column. Set display: flex on a container, then use justify-content to align items along the main axis and align-items to align them along the cross axis.

.nav-bar { display: flex; justify-content: space-between; align-items: center; gap: 16px; }

Flexbox shines for one-dimensional layouts — navbars, button groups, and centering content both horizontally and vertically with almost no code.

Lesson 5

Grid

CSS Grid handles two-dimensional layouts — rows and columns at once. Define a track structure with grid-template-columns, then let items fall into place, or position them explicitly.

.gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

repeat(3, 1fr) creates three equal-width columns. Grid is the natural choice for page layouts, image galleries, and dashboards.

Lesson 6

Responsive Design & Transitions

Media queries apply CSS conditionally based on viewport size, letting one stylesheet adapt to phones, tablets, and desktops. Transitions smooth out property changes, like a hover effect, instead of snapping instantly.

.card { transition: transform 0.2s ease; } .card:hover { transform: translateY(-4px); } @media (max-width: 600px) { .gallery { grid-template-columns: 1fr; } }

Design "mobile-first": write your base styles for small screens, then use min-width media queries to add complexity as the viewport grows.

Lesson 7

Pseudo-classes & Pseudo-elements

A pseudo-class selects an element based on its state or position, without needing an extra class in the HTML — :hover, :focus, and :nth-child() are the ones you'll reach for constantly. A pseudo-element like ::before or ::after generates content that isn't in the HTML at all.

.nav-link:hover { color: #fff; } .lesson:nth-child(odd) { background: #1e1a15; } .badge::before { content: "★"; margin-right: 6px; }

:nth-child(odd) is handy for zebra-striping rows in a list without touching the markup. ::before/::after always need a content property — even an empty string — or the browser won't render them; they're perfect for decorative icons, quote marks, or little corner labels.

Lesson 8

Positioning

The position property controls how an element is placed. static is the default flow; relative nudges an element from its normal spot while still reserving that space; absolute removes it from the flow and places it against its nearest positioned ancestor; fixed pins it to the browser window; sticky behaves like relative until a scroll threshold, then sticks like fixed.

.back-to-top { position: fixed; right: 24px; bottom: 24px; } .site-header { position: sticky; top: 0; z-index: 100; }

fixed is exactly how the little arrow button in the corner of this page stays put in the same spot no matter how far you scroll — and sticky is what keeps the header glued to the top of the viewport as you read. z-index only has an effect on positioned elements (anything other than static), and it decides which one sits on top when two overlap.

Lesson 9

Animations & Keyframes

A transition animates between two states in response to a change, like a :hover. A @keyframes animation is more powerful — it can run automatically on page load, move through as many steps as you define, and loop forever without any trigger at all.

@keyframes float { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-8px); } } .icon { animation: float 3s ease-in-out infinite; }

Name the animation, define what happens at each percentage of its timeline, then attach it with the animation shorthand: duration, easing, and infinite to loop. It's how the drifting embers and the gently swinging logo mark on this page stay in motion without any JavaScript driving the movement itself.

Lesson 10

Specificity

When two rules target the same element, the browser doesn't just use whichever comes last — it weighs each selector's specificity first. Inline styles win over everything; an ID beats any number of classes; a class, attribute, or pseudo-class beats any number of elements; a bare element or pseudo-element selector is the weakest.

p { color: blue; } /* element: weight 0-0-1 */ .warning { color: orange; } /* class: weight 0-1-0 */ #alert-banner { color: red; } /* ID: weight 1-0-0 */ <p style="color: green">...</p> /* inline: always wins */ /* #alert-banner beats .warning, which beats p, no matter the order */

Rather than reaching for !important to force a win, keep selectors as flat and class-based as possible — it's the easiest specificity level to reason about and override later.

Lesson 11

Custom Properties (CSS Variables)

A custom property stores a reusable value — a color, a spacing unit, a font — under a name starting with two dashes. Defined on :root, it's available everywhere and read with var(), with an optional fallback if it's ever missing.

:root { --ember: #ff6b35; --radius: 12px; --gap: 16px; } .card { border-radius: var(--radius); gap: var(--gap, 12px); /* 12px fallback if --gap isn't set */ border: 1px solid var(--ember); }

Unlike a Sass variable, a custom property is live in the browser — Frontend Forge's own light/dark theme toggle works by redefining --bg, --text, and friends on [data-theme="light"], and every rule using var(--bg) updates instantly with no rebuild step.

Lesson 12

Gradients, Shadows & Filters

linear-gradient() and radial-gradient() blend two or more colors without an image file. box-shadow drops a shadow behind an element's box, while filter applies effects — blur, brightness, grayscale — to everything drawn inside it, pixels included.

.hero-banner { background: linear-gradient(100deg, #ff6b35 0%, #ffb627 100%); box-shadow: 0 24px 48px -20px rgba(0,0,0,0.5); } .card:hover { filter: brightness(1.1); }

This exact gradient technique is how the glowing "Frontend Forge" title text on the homepage gets its ember-to-gold color shift — a gradient background clipped to the text shape with background-clip: text.

Lesson 13

Transforms & 3D

transform moves, rotates, scales, and skews an element without disturbing the rest of the page's layout — unlike changing top/left, it doesn't trigger a reflow, so it's the cheapest property to animate. Chain multiple functions in one declaration and they apply left to right.

.course-card:hover { transform: translateY(-8px) scale(1.02) rotate(-0.5deg); transition: transform 0.25s ease; } .badge-icon { transform: perspective(400px) rotateY(15deg); }

Set transform-origin to change the pivot point for scale/rotate, and reach for will-change: transform only when an animation is actually janky — overusing it wastes GPU memory.

Lesson 14

calc(), clamp() & Modern CSS Functions

calc() mixes units in one expression — like a sidebar that's the viewport minus a fixed header. clamp(min, preferred, max) goes further: it picks a fluid value that scales with the viewport but never goes below or above the bounds you set, which is often enough to replace a whole set of media queries for font sizing.

.sidebar { width: calc(100% - 240px); } h1 { font-size: clamp(1.75rem, 4vw + 1rem, 3.5rem); } .container { width: min(90%, 1100px); padding: max(16px, 4vw); }

clamp() reads as "grow with 4vw + 1rem, but never shrink past 1.75rem or exceed 3.5rem" — one line replacing three breakpoints of font-size overrides. min() and max() work the same way for widths and spacing.

Lesson 15

Grid Template Areas

Naming regions of a grid with grid-template-areas turns a layout into readable ASCII art — each string is a row, each word a named cell, and repeating a name merges cells into one region. Child elements then just declare which named area they belong to.

.page { display: grid; grid-template-columns: 220px 1fr; grid-template-areas: "header header" "sidebar main" "footer footer"; } .site-header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .site-footer { grid-area: footer; }

Leave a cell out of the layout entirely with a . placeholder, and reorder the whole page for mobile just by rewriting the area strings inside a media query — no need to touch the HTML source order.
