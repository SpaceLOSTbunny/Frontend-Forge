# ⚒️ Frontend Forge

> **Hammer Your Code to Perfection.**

**Frontend Forge** is an interactive, self-paced programming learning platform designed for people who learn best by building. It combines structured lessons, hands-on coding, quizzes, progress tracking, achievements, and certificates into one modern web application.

---

## 🚀 Features

### 📚 Multi-Language Learning

Learn and practice multiple programming languages through dedicated course sections:

* **HTML** — Web page structure and fundamentals
* **CSS** — Styling, layouts, animations, and responsive design
* **JavaScript** — Programming, DOM manipulation, events, and projects
* **Python** — Scripting, syntax, OOP, and programming fundamentals
* **Java** — Object-oriented programming and fundamentals
* **C++** — Pointers, memory management, and performance concepts

### 💻 Interactive Coding Playground

Write and experiment with code directly inside the browser.

* HTML editor
* CSS editor
* JavaScript editor
* Python editor
* Java editor
* C++ editor
* Live preview
* Console output
* Ready-to-use coding examples
* Run and reset controls
* Keyboard shortcut support (`Ctrl/Cmd + Enter`)

Python, Java, and C++ execution uses an online code-execution API and therefore requires an internet connection.

### 🧠 Practice & Quizzes

Test your programming knowledge with:

* Multiple-choice quizzes
* Fill-in-the-blank coding questions
* Randomized questions
* Topic-based filtering
* Separate question pools for MCQs and coding snippets

### 📊 Progress Tracking

Track your learning journey with browser-based progress storage.

* Courses started
* Best quiz score
* Badges earned
* Learning progress
* Reset progress option

### 🏆 Achievements & Certificates

Earn badges as you progress and unlock certificates by meeting the required quiz and practice scores for individual topics.

Certificates can be personalized with your name and downloaded.

### 🎨 Modern User Interface

* Responsive design
* Vibrant visual style
* Interactive navigation
* Dark/light theme support
* Smooth user experience
* Mobile-friendly layout

### 📱 Progressive Web App

Frontend Forge includes **PWA support**, allowing the website to behave more like an installable application.

* Web App Manifest
* Service Worker
* App icons
* Standalone display mode
* Offline-capable architecture

## 💡 Why Frontend Forge?
